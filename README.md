# Тёплый день — интерактивный сайт кофейни

Рабочий демонстрационный сайт по заданию «Сайт кофейни с моушен-графикой». Интерфейс на русском языке. **Никакие реальные заказы не принимаются, платежи не проводятся.** Название, цены, адрес, время работы, контакты и история кофейни — примеры, а не реальные данные.

## Как запустить

Требуется Node.js 20.19+ или 22+.

```bash
npm install
npm run dev
```

Откройте адрес из терминала, обычно `http://localhost:5173`.

Проверка сборки:

```bash
npm run build
npm run preview
```

## Как заменить фото, тексты, цены и напитки за 5 минут

1. Откройте `src/config/site.config.ts`: замените название, слоган, адрес, часы, телефон, социальные сети. Если есть публичная ссылка на встраиваемую карту, вставьте её в `mapUrl`.
2. Откройте `src/config/menu.config.ts`: поменяйте названия напитков, описания, цены S/M/L, рецепты-слои. Примеры цен указаны в рублях.
3. Положите файлы в `public/images/` (например, `hero.jpg`, `about-1.jpg` и `menu/cappuccino.jpg`) и укажите пути в `src/config/images.config.ts`. Отсутствующие изображения автоматически заменяются оформленными заглушками. Для hero: WebP/JPEG до 1920px; для карточек: WebP до 800px.
4. Измените палитру CSS-переменных в начале `src/styles/main.css` и параметр `accent` в `site.config.ts` (акцент в CSS обновите отдельно).
5. Выполните `npm run build` и опубликуйте обновлённый сайт.

## Как работает демонстрационный заказ

Карусель: кнопки-стрелки, клавиши ←/→, свайп или перетаскивание. Размер, молоко, сироп, дополнительный шот и имя влияют на итоговый заказ и изображение стаканчика. Проигрывается GSAP-таймлайн приготовления продолжительностью примерно 8–10 секунд с пропуском; этапы зависят от напитка. Финальный экран показывает стаканчик с именем. Кнопка «Поделиться PNG» скачивает карточку на компьютер.

## Стек и особенности

Vite, React 18, TypeScript, Tailwind CSS, CSS-переменные, GSAP, Framer Motion, Zustand, SVG-стаканчик, html-to-image. Адаптивная верстка, тёмная тема, загрузка изображений с fallback, базовые SEO-мета-теги и schema.org JSON-LD, поддержка `prefers-reduced-motion`.

## Публикация

Vercel / Netlify: импортируйте каталог как Git-репозиторий. Команда сборки `npm run build`, выходной каталог `dist`; проект Vite. Перед публикацией замените демонстрационные сведения, фотографии, favicon, SEO-тексты и контактные данные.

## Принятые допущения

- По заданию сайт без бэкенда и оплаты — поэтому покупка **имитируется**. Номер заказа локальный, не сохраняется в серверной базе.
- Поскольку реальный бренд не задан, использовано демонстрационное название «Тёплый день», примерные цены и пустые ссылки на соцсети.
- При отсутствии реальных фотографий отображаются цветные заглушки.
- Категория десертов предусмотрена, но не наполнена: исходный документ содержит список напитков, без десертов.
- Пункт «собственная реализация карусели с drag/swipe» реализован обработчиками мыши и касания плюс Framer Motion для переходов.
- Перед коммерческим использованием необходимы реальная интеграция заказов, политика обработки данных при сборе данных клиентов, проверка доступности/производительности и тест на целевых устройствах. Lighthouse-оценки не заявляются без измерений.
